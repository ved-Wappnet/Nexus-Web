# Nexus Market — frontend

Angular 22 standalone storefront. This folder is a complete app and can be its own git remote.

```bash
npm start
```

Opens `http://localhost:4200`.

`src/environments/environment.ts`:

- `useMockApi: true` — UI only, no NestJS
- `useMockApi: false` — calls NestJS (`proxy.conf.json` → `http://localhost:3000`)
